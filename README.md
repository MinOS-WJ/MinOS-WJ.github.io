# MinOS-WJ

MinOS-WJ 是一个纯静态的浏览器工作台，使用原生 HTML、CSS 和 JavaScript 构建，适合直接部署到 GitHub Pages。

## 内容

- **工具**：Markdown、加解密、时间、网络诊断、函数绘图和图形实验。
- **快捷入口**：搜索引擎、AI 网页端、计算机社区与论坛、软件和系统镜像。
- **游戏**：五子棋、贪吃蛇、飞机大战、扫雷、恐龙跑酷和舒尔特方格。
- **资讯**：百度新闻、BBC、中国新闻网和科学网等 RSS 阅读页。
- **AI**：API 对话、提示词工作台、Token 费用估算和模型排行榜。

## GitHub Pages 部署

1. 将项目推送到 GitHub 仓库。
2. 打开仓库的 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**。
4. 选择要发布的分支和根目录 `/`，保存设置。
5. 等待 GitHub Pages 完成发布，然后访问生成的站点地址。

项目根目录包含 `.nojekyll`，用于确保静态文件按原路径发布。页面使用相对路径，因此可以部署到用户站点或项目站点。

```text

```

## 模型排行榜

排行榜页面位于 `page/ai/leaderboard.html`，读取仓库内的 `data/latest.json`，不依赖后端接口。数据文件包含 11 个领域的榜单快照，以及模型厂商、得分、价格、能力标签和上下文窗口等信息。

页面支持：

- 按领域切换榜单；
- 搜索模型、厂商和能力标签；
- 按开放权重、得分、价格、发布日期和上下文窗口筛选或排序；
- 查看前三名、分页结果和模型详情；
- 查看原始榜单记录。

如需更新排行榜，请直接替换 `data/latest.json`，并保持现有 JSON 结构：顶层使用 `domains` 对象，每个领域包含 `rankings` 数组。

## 本地打开

直接双击 HTML 会使用 `file://` 协议。由于浏览器通常会阻止 `fetch()` 读取本地 JSON，排行榜页面可能无法加载数据。

推荐直接使用 GitHub Pages 地址访问。需要本地预览时，可使用任意静态文件服务器，例如：

```bash
python -m http.server 8000
```

然后访问 `http://127.0.0.1:8000/`。项目本身不包含本地服务器脚本，也不依赖构建工具或 Node.js。

## 隐私与外部服务

- AI API Key 只保存在当前页面内存中，不会写入仓库。
- 新闻、出口 IP 和部分网络工具会请求对应的第三方服务；是否可用取决于浏览器网络环境和跨域策略。
- 快捷入口页面只提供外部站点链接，不代理、不存储第三方账号信息。
